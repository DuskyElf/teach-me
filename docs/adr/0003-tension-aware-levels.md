# Tension-awareness as level gauge

User understanding is gauged primarily by tension-awareness — whether they can articulate contested points without defaulting to one side — not by recall or confidence.

Levels: Unknown → Confused → Aware → Confident. Each level implies tension-handling ability, not just familiarity.

Reason: The system targets unknown unknowns discovery. A user who "feels confident" but defaults to one framing of a contested concept is still at Aware level. The Socratic process validates self-assessments and surfaces overconfidence.

Reverting this would mean using simpler familiarity-based levels — easier, but misses the core purpose of tension-aware learning.
